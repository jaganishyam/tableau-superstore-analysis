# Tableau Superstore Sales Analysis

## Project Overview

This project analyzes the Sample Superstore dataset using Tableau. The objective was to identify sales trends, profitability patterns, regional performance, and category-level insights through interactive visualizations.

## Tools Used

* Tableau
* Sample Superstore Dataset
* Data Visualization
* Business Analysis

## Dashboard Components

### 1. KPI Overview

Tracks Sales, Profit, Profit Ratio, and Quantity across different years.

### 2. Regional Performance Map

Visualizes sales and profitability across states to identify high-performing and underperforming regions.

### 3. Category Analysis

Compares sales by sub-category and highlights profitable versus loss-making product groups.

### 4. Monthly Sales Trend & Forecast

Analyzes sales trends over time and uses forecasting to estimate future performance.

## Key Insights

1. Sales increased over time, but profit growth was inconsistent.
2. Several states generated strong sales but relatively low profit margins.
3. A small number of sub-categories contributed a large share of total revenue.
4. Certain high-sales categories produced low or negative profits.
5. Sales showed recurring seasonal peaks, with forecasts indicating continued growth.
